# docode Privacy Policy

Effective date: September 20, 2026

docode is a Chrome extension that adds developer-oriented code editing and formatting to Google Docs. This policy explains how docode handles data.

## Data docode handles

docode may process the following information on the user's device:

- Code and other text that the user types into the docode editor.
- Text that the user selects in Google Docs and explicitly asks docode to edit.
- Clipboard content when the user pastes likely code into Google Docs, inserts formatted code, or uses manual paste recovery.
- The identifier of the current Google Doc, used only as part of a local storage key.
- Local editor drafts, code fingerprints, selected language identifiers, and timestamps used for draft recovery and language memory.

## How data is used

This information is used only to provide docode's user-facing features: code editing, syntax highlighting, language detection, Smart Paste, formatted insertion, block updates, and local draft recovery.

## Local storage and retention

docode stores data using Chrome's local extension storage. A draft is saved while the editor is in use and is removed after successful insertion. Language memory stores a non-cryptographic code fingerprint and language choice for up to 100 recently formatted blocks per document. Local data remains until docode removes it during normal use, the user clears the extension's storage, or the extension is uninstalled.

## Data sharing and transmission

docode does not send document text, clipboard content, drafts, document identifiers, or usage information to the developer or to third parties. docode has no analytics, advertising, tracking, remote code, or developer-operated server. Google Docs and Chrome continue to process data under their own terms and privacy policies.

docode does not sell user data. It does not use or transfer user data for advertising, creditworthiness, or any purpose unrelated to its single purpose.

## Limited Use

docode's use of information received from Google services complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data access is limited to providing and improving docode's visible code-editing features. Humans do not read user content through docode.

## Security

All docode processing and storage occur locally in the user's browser. Because docode does not transmit user data to the developer or third parties, there is no developer-operated data transmission or server-side storage.

## User choices and deletion

To delete all locally stored docode data, users can remove the extension or clear its extension storage through Chrome.

## Changes to this policy

If docode's data practices change, this policy and the Chrome Web Store privacy disclosures will be updated before the changed behavior is released.
